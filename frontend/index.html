Score many customers from a CSV file

Upload a CSV with one customer per row to get a list ranked by churn risk – ready for a retention campaign. Columns can use the original dataset names (e.g. Monthly Charge) or the API names (e.g. monthly_charge). A Customer ID column is kept to identify customers. Up to 5,000 rows.
